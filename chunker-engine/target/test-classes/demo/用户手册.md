# Smart-Chunker 用户手册

## 第一章 快速入门

Smart-Chunker 是一款为大模型私有化部署打造的纯 Java 智能文本清洗与预处理引擎。
它基于 Markdown 抽象语法树进行智能解析，确保语义完整性。

### 1.1 环境要求

- JDK 17 或以上版本
- Maven 3.6+
- 操作系统：Windows / Linux / 麒麟 V10

### 1.2 安装步骤

首先，克隆项目到本地：

```bash
git clone https://github.com/example/smart-chunker-java.git cd smart-chunker-java mvn clean install -DskipTests
```


## 第二章 核心功能

### 2.1 代码块保护

传统切片工具会将代码块拦腰截断，导致大模型产生幻觉。Smart-Chunker 自动识别代码块并强制保持完整。

以下是一段完整的 Java 代码示例：

```java
package com.example.demo;

import org.springframework.boot.SpringApplication; import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication 
public class DemoApplication { 
    public static void main(String[] args) { 
        SpringApplication.run(DemoApplication.class, args); 
        System.out.println("服务启动成功！"); 
    } 
}
 ```


这段代码无论多长，都不会被切分成两段。

### 2.2 上下文路径

每个切片会自动带上标题层级路径，例如：

- 如果内容在 `## 第二章 核心功能` 下的 `### 2.1 代码块保护` 中，
- 那么上下文路径就是：`Smart-Chunker 用户手册 > 第二章 核心功能 > 2.1 代码块保护`

### 2.3 配置参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| maxChunkSize | 800 | 单个切片最大字符数 |
| overlapSize | 100 | 相邻切片重叠字符数 |
| protectCodeBlock | true | 是否保护代码块不被截断 |
| includeContextPath | true | 是否拼接标题路径 |

## 第三章 高级用法

### 3.1 多线程批量处理

对于大量文档，可以使用 ChunkEngine 进行并发处理：

```java
ChunkEngine engine = new ChunkEngine(); 
ChunkConfig config = new ChunkConfig(500, 50); 
BatchResult result = engine.processDirectory(new File("/data/docs"), config); 
System.out.println("处理了 " + result.getFileCount() + " 个文件"); 
System.out.println("生成了 " + result.getTotalChunkCount() + " 个切片"); 
System.out.println("耗时: " + result.getElapsedMs() + " ms"); 
engine.shutdown();
```


### 3.2 Spring Boot 集成

引入 starter 依赖后，在 application.yml 中配置：

```yaml
smart-chunker: 
  enable: true
  strategy: 
    max-chunk-size: 800
    overlap-size: 100
```


然后在 Service 中直接注入使用：

```java
@Autowired private SmartChunkerTemplate chunkerTemplate;

public void processDocument() { 
    List<DocumentChunk> chunks = chunkerTemplate.process(new File("doc.md")); 
    for (DocumentChunk chunk : chunks) { 
        System.out.println(chunk.getContextPath()); 
        System.out.println(chunk.getContent()); 
    } 
}
```
